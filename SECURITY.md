# Security reports

Report a suspected security problem privately to **selzystudio@gmail.com** with the Reva version, affected feature and a minimal reproduction using synthetic data. Do not post private recovered media, credentials, signing keys or full disk images in public issues. Do not overwrite a real drive to reproduce a problem.

No bounty or response deadline is promised. Updater signing is separate from Windows Authenticode. This repository contains binary distribution materials; the application source is private.
