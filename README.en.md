# Reva by Selzy Studio

Find files left on USB and external disks after deletion or a quick format. **Scanning and recovery are free.** Donations are optional. [한국어](README.md)

[Windows x64 installer](https://github.com/selzystudio-01/Reva/releases/download/v1.0.3/Reva_1.0.3_x64-setup.exe) · [Full portable ZIP](https://github.com/selzystudio-01/Reva/releases/download/v1.0.3/Reva_1.0.3_portable.zip) · [Codec corresponding source](https://github.com/selzystudio-01/Reva/releases/download/v1.0.3/Reva-codec-sources-1.0.3.zip)

Requires Windows 10 version 2004 or later / Windows 11 x64 and Microsoft Edge WebView2 Runtime. The installer may download that runtime from Microsoft. Raw device access requires administrator permission. Choose deleted-record or deep scanning, inspect results with categories, search, list/tile views and supported previews, then save to **another physical disk**. Do not write to the recovery source.

Recovery is not guaranteed for every format or damaged/fragmented file. Missing name records result in temporary names. Recoverability and preview support differ, including HEIC and camera RAW. [Supported formats](SUPPORTED_FORMATS.md) · [User guide](USER_GUIDE.md)

The app source is private. This repository contains distribution documentation, static pages and policies; binaries are in Releases. Required codec corresponding source is provided separately. Preserve the existing LICENSE and THIRD_PARTY_NOTICES in each release; this README does not replace those licenses.

The installed edition validates signed updates and asks before installation. Portable users replace the entire ZIP; the Store edition uses Microsoft Store updates. Current direct binaries are **Authenticode unsigned** and Windows may show a warning. Updater signatures are distinct from Windows publisher signatures. Unconfigured local candidates through 1.0.2 need one manual installation of the first public version.
