파일 검사·복구·사진/영상 미리보기는 사용자의 컴퓨터에서 처리합니다. 파일 이름, 경로, 내용과 복구 보고서를 업로드하지 않습니다. 원본은 읽기 전용으로 열며, 저장 보고서는 사용자가 선택한 복구 결과 폴더에 남습니다. 앱 설정과 화면 언어·후원 안내 숨김·자동 업데이트 확인 설정은 현재 앱 프로필에 저장됩니다. 오류 자료는 자동 전송하지 않습니다.

GitHub 직접 배포판의 자동 업데이트 확인을 켜면, 시작 시와 실행 중 주기적으로 설정된 공개 GitHub Releases 주소에 버전 확인 요청을 보냅니다. 수동 확인도 같은 요청을 사용합니다. GitHub는 일반 HTTPS 요청의 IP 주소·요청 시각·클라이언트 정보 등을 처리할 수 있습니다. 업데이트 확인을 끄면 자동 요청을 중지할 수 있습니다. 설치 파일은 설치 확인을 선택한 뒤 받으며, 앱에 포함된 공개 키와 서명된 버전으로 검증합니다. 파일 이름이나 복구 데이터는 업데이트 요청에 포함하지 않습니다. Store판은 앱 자체 GitHub 업데이트를 실행하지 않고 Microsoft Store의 업데이트 경로를 사용합니다.

# Reva privacy and network information

2026-10-27 · Selzy Studio

File scanning, recovery and photo/video previews run on your computer. Reva does not upload filenames, paths, file contents or recovery reports. Sources are opened read-only. Reports are saved in the recovery output folder you choose. Language, support-notice visibility and automatic update preferences are stored in the current app profile. Error details are not automatically submitted.

When automatic update checking is enabled in the GitHub installed edition, Reva requests version information from the configured public GitHub Releases address at startup and periodically while running. Manual checks use the same service. GitHub may process IP addresses, request times and ordinary HTTP client information. You can disable automatic checks. An installer is downloaded only after you confirm installation and is validated against the app's public key and signed version. These requests do not include recovery data or filenames. The Store edition uses Microsoft Store updates instead of the app's GitHub updater.

The donation button opens Selzy Studio's Ko-fi page in your browser. Reva does not receive payment details or confirmation of donation. External payment providers apply their own policies. Hiding the support notice is a local preference, not payment verification. Donations are not required to scan or recover files.

The direct installer may download Microsoft WebView2 Runtime if missing. Windows, WebView2 and Microsoft Store installation or updates may communicate with Microsoft services. Microsoft, GitHub and Ko-fi apply their own policies to their services. Reva has no separate analytics or advertising-tracking server.

Operator: Selzy Studio. Support/privacy contact: selzystudio@gmail.com. Website: https://selzystudio.com/. If you email us, your email address and the information you choose to send are handled through Gmail. Do not attach original recovery data or sensitive paths. You can request deletion of correspondence at the same address. Reva does not operate a separate support database. The operator retains support correspondence for 90 days after resolution, then deletes it. This is an operational policy managed in Gmail, not an automatic email-deletion feature of Reva.

This policy and the Reva information page are hosted on GitHub Pages. GitHub may process ordinary web-request information such as IP addresses and access times. Page requests and update checks do not include recovery filenames, paths or contents.
