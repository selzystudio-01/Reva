# Reva by Selzy Studio

소중한 파일을, 다시. Windows USB·외장디스크에서 삭제되거나 빠른 포맷 후 남아 있는 파일을 찾는 복구 도구입니다. **검사와 복구는 무료**, 후원은 선택 사항입니다. [English](README.en.md)

최초 설치 파일을 게시하고 있습니다. [릴리스 목록](https://github.com/selzystudio-01/Reva/releases)에서 게시 상태를 확인하세요.

Windows 10 2004 이상 또는 Windows 11 **x64**, Microsoft Edge WebView2 Runtime이 필요합니다. 설치기는 런타임이 없으면 Microsoft에서 다운로드할 수 있습니다. 실제 장치의 원시 읽기는 관리자 권한이 필요합니다.

1. 최근 삭제는 삭제 기록, 빠른 포맷 뒤에는 정밀 검사를 선택하세요.
2. 종류 필터·이름 검색·정렬·리스트/타일·지원 사진/영상 미리보기로 결과를 확인하세요.
3. 원본과 **다른 물리 디스크**에 복구하세요. 원본에 새 데이터를 쓰지 마세요.

모든 형식/손상/조각난 파일의 복구를 보장하지 않습니다. 원래 이름 기록이 없으면 임시 이름을 사용합니다. HEIC/카메라 RAW 등은 복구 지원과 앱 내 미리보기 지원이 다릅니다. [지원 범위](SUPPORTED_FORMATS.md) · [사용 안내](USER_GUIDE.md)

앱 소스는 비공개입니다. 이 저장소에는 배포 안내·정적 소개·정책만 보관하며 설치 파일은 Releases에 제공합니다. 필요한 제3자 코덱 대응 소스는 별도 ZIP입니다. 기존 LICENSE와 제3자 고지는 각 배포에 보존하며 이 README는 기존 권리를 변경하지 않습니다.

설치형은 서명된 업데이트를 확인하고 설치 전 동의를 받습니다. 포터블은 전체 ZIP 수동 교체, Store판은 Microsoft Store 업데이트를 사용합니다. **Windows Authenticode 미서명**으로 경고가 표시될 수 있습니다. updater 서명과 Windows 게시자 서명은 서로 다릅니다. 기존 미연결 로컬 후보(~1.0.2)는 최초 공개 버전으로 한 번 수동 설치해야 합니다.
